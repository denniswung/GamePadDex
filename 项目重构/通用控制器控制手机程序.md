# 通用控制器控制手机程序 · 完整需求文档

## 0. 关键优化点

1. **“左右摇杆可切换”明确为“角色互换”**：左/右摇杆可在“光标控制”和“滑动/滚动控制”两种角色间互换，而非模糊的“可切换”。
2. **“基于光标焦点”定义为“焦点优先、光标锚定、无焦点回退”**：滑动和滚动都作用于当前光标所在的可滚动焦点；焦点不可滚动时回退到光标锚点所在容器；仍无则走系统默认。
3. **“屏幕滑动 / 鼠标滚动可切换”明确为两种输出后端**：手势滑动（触摸 swipe）和滚轮滚动（wheel），全局可切换，用于兼容测试，均支持持续输出。
4. **按键配置模型化**：每个可改按键有二级配置页，包含单击/长按/双击/作为发起键的组合；明确判定优先级和组合等价继承规则。
5. **测试前置增加“链路自检”**：链路未通过不进入功能测试，避免把环境问题误判为功能缺陷。
6. **新增“手柄接入点亮屏幕”**：作为低频系统动作独立配置，只负责从灭到亮，不自动解锁，不占用按键映射表。

---

## 1. 项目目标与范围

做一个**通用控制器控制手机**的常驻程序：读取手柄输入，按可配置映射注入鼠标、键盘、触摸手势、滚轮和系统动作。

- 首个适配型号：Xbox Series X|S；架构上支持通过 keylayout/映射表扩展其他控制器。
- 运行环境：Android 手机全局；root 权限下使用 evdev 读取 + uinput 注入，低延迟。
- 除左右摇杆的基础角色外，其余按键功能均可更改。
- 提供配置持久化、导入导出、恢复默认、按 Profile 保存。
- 支持手柄 USB/蓝牙接入时自动点亮屏幕。

## 2. 术语

| 术语 | 定义 |
|---|---|
| 光标角色 | 摇杆控制鼠标指针移动 |
| 滑动/滚动角色 | 摇杆控制当前焦点容器的滑动或滚动 |
| 焦点 | 当前可滚动、可操作的目标控件/容器 |
| 光标锚点 | 当前鼠标指针所在坐标，用于无焦点时的回退定位 |
| 发起键 | 组合键中先按下的键，决定组合命名空间 |
| 参与键 | 组合中后按下的键 |
| 等价组合 | 发起键与参与键相同、顺序相反的组合，如 X+A 与 A+X |
| 手势滑动 | 注入触摸 down-move-up，模拟手指滑动 |
| 滚轮滚动 | 注入滚轮事件，模拟鼠标滚轮 |
| 持续输出 | 按住摇杆/按键时按间隔连续触发滑动或滚动 |
| 接入点亮 | 手柄 USB/蓝牙接入时，若屏幕熄灭则自动点亮至锁屏 |

## 3. 输入链路与前提

- 输入链路：手柄 → evdev → 守护进程 → uinput/系统接口 → 手机响应。
- 组合判定窗口默认 **50ms**，可调 30–100ms。
- 按键按下先进入 pending；组合优先并抑制参与键的单键动作；单击动作延迟到判定窗口结束，但按下瞬间给短震。
- 守护进程只允许固定命令白名单：鼠标、键盘、媒体、音量、通知栏、开关屏、强停当前前台包等；不开放任意 shell。
- 所有模式切换、组合识别、持续输出档位给不同震动/Toast 反馈。
- 权限缺失时给出明确提示和回退动作，不静默失效。

## 4. 摇杆功能需求

### 4.1 角色切换

- 支持两种角色预设：
  - 预设 A：左摇杆 = 光标，右摇杆 = 滑动/滚动（默认）
  - 预设 B：左摇杆 = 滑动/滚动，右摇杆 = 光标
- 切换即时生效并持久化；切换时停止当前输出、清空惯性、给震动确认。
- 左右摇杆的基础角色不开放为任意动作映射；L3/R3 属于可改按键。

### 4.2 光标控制

- 死区默认 8%，可调 5%–12%；分静止死区和起步补偿，避免“推了不动、再推就窜”。
- 响应曲线默认幂曲线 1.5 次，低速平缓、高速可跨屏；提供总速度倍率。
- 滤波默认 One Euro 或低速强 EMA，高速减弱滤波保跟手。
- uinput 输出使用浮点累加、亚像素精度，避免轻推一跳一跳。
- 光标靠近屏幕边缘可选减速 30%–50%。
- 光标速度全局可调，默认 1.0×，范围 0.2×–3.0×，实时生效并持久化。

### 4.3 滑动/滚动控制

- 输出模式全局可切换：**手势滑动 / 滚轮滚动**，用于兼容测试，切换后即时生效并持久化。
- 持续输出：按住摇杆超过启动延迟（默认 150ms）后，按重复间隔（默认 100ms）连续触发；支持加速（加速后 30–50ms）；松手立即停止。
- 单次推杆默认产生一次明确距离的滑动/滚动（默认 40%–60% 屏高/宽），长推进入连续输出。
- 轴向锁定：过死区后判定主方向并锁定 X 或 Y 轴，防斜推同时上下+左右。
- 横向输出可带惯性，指数衰减默认 0.93/帧；摇杆快速回中时加速衰减。
- 滑动速度全局可调，默认 1.0×，范围 0.2×–3.0×；持续间隔、步长可高级调节。
- 与 LB/RB 等按键滚动互斥：最近有效输入抢占，避免速度叠加。

### 4.4 焦点锚定规则

无论滑动还是滚动，均按以下顺序确定作用对象：

1. **焦点优先**：当前光标所在位置的可滚动焦点容器。
2. **光标锚定回退**：焦点不可滚动时，以光标坐标为锚点，作用于该坐标所在窗口的默认可滚动容器。
3. **系统默认回退**：仍无可滚动对象时，手势滑动从光标位置附近开始；滚轮滚动先将光标定位到焦点/锚点再发送滚轮事件。
4. 焦点在持续输出过程中变化时，下一次输出重新锚定，不延续旧目标。

## 5. 按键映射与配置模型

### 5.1 可改按键范围

- 除左右摇杆基础角色外，所有按键可改：A/B/X/Y、LB/RB、LT/RT、L3/R3、Start/Select、Guide/Share、方向键等。
- 每个可改按键有**二级配置页**，包含四个区块：
  1. 单击
  2. 长按（默认 500ms，可调 300–1000ms）
  3. 双击（双击窗口默认 280ms，可调 200–400ms）
  4. 组合（作为发起键）

### 5.2 单键判定顺序

按键按下后的判定优先级：

1. **组合等待**：作为发起键进入组合窗口（默认 50ms）。
2. **组合匹配**：窗口内出现参与键 → 执行组合，抑制发起键和参与键的单键动作。
3. **长按**：无组合时，按住超过长按阈值 → 触发长按，取消单击/双击候选。
4. **双击**：长按阈值前释放 → 进入双击窗口；窗口内再次按下 → 双击。
5. **单击**：双击窗口结束无第二击 → 单击。

长按触发后释放不再触发单击/双击；双击成功后不触发单击。

### 5.3 组合键规则

- 组合以**发起键**为命名空间：`X + A` 与 `A + X` 是两个独立组合。
- **等价继承**：若只配置了 `X + A`，未单独配置 `A + X`，则 `A + X` 继承 `X + A` 的动作；若 `A + X` 单独配置，则覆盖继承，各自独立。
- 同时按下无法区分先后时：按时间戳先按下的键为发起键；同一扫描周期内按固定优先级并记录日志。
- 组合条目包含：发起键、参与键、动作、参数、启用开关、优先级。
- 组合优先于所有单键动作；组合期间抑制参与键的 D-pad/摇杆/肩键默认输出。

### 5.4 动作库与配置

- 动作库至少包含：鼠标左/右键、返回、Home、多任务、媒体播放/暂停、上一首/下一首、音量、通知栏、开关屏、强停当前前台应用、无动作。
- 每个动作可带参数（步长、重复间隔、是否持续）。
- 支持配置导入/导出、恢复默认、按 Profile 保存（默认/精细/信息流）。
- 配置修改实时生效；重启后恢复。

## 6. 手柄接入点亮屏幕

### 6.1 功能定义

- 当手柄通过 **USB 或蓝牙**接入手机时，若屏幕处于熄灭/息屏状态，自动点亮屏幕（显示锁屏，不自动解锁，除非另行配置）。
- 屏幕已亮时接入不重复点亮，不改变当前界面状态。
- 点亮动作由守护进程执行，不依赖用户手动按键。

### 6.2 实现方式（root）

- **接入检测**：
  - 监听 `/dev/input` 的设备添加事件（inotify 或轮询 `/proc/bus/input/devices` 变化），匹配 Xbox 手柄的 vendor/product ID。
  - 蓝牙接入可额外监听 `bluetooth` 广播或 `dumpsys input` 中设备列表变化。
  - 检测到目标手柄节点出现 → 触发点亮流程；节点消失 → 记录断开，不触发点亮。
- **屏幕状态判断**：
  - 读取 `dumpsys power` 中 `mWakefulness`（`Awake` / `Asleep` / `Dozing`），仅当非 `Awake` 时执行点亮。
  - 或读取 `dumpsys display` 的屏幕状态字段；以 `mWakefulness` 为主，兼容不同 ROM。
- **点亮动作**：
  - 首选 `input keyevent 224`（`KEYCODE_WAKEUP`），root 下直接执行，语义明确，不会像 `KEYCODE_POWER` 那样误关屏。
  - 备选：root 进程通过反射/PowerManagerService 调 `wakeUp()`，但不同 ROM 兼容性不如 `KEYCODE_WAKEUP`。
  - 执行后给短震 + Toast“手柄已接入，屏幕已点亮”，便于确认。

### 6.3 防重复与边界

- **防抖窗口**：同一手柄在 3s 内的重复添加事件只触发一次点亮。
- **仅点亮不自动解锁**：默认停留在锁屏；如需自动解锁，作为独立配置项（root 下可 `dismissKeyguard`），默认关闭。
- **屏幕已亮不重复**：接入时若 `mWakefulness=Awake`，只记录日志和震动，不执行点亮。
- **电量/异常保护**：连续多次接入失败时记录日志并停止重试，避免反复唤醒耗电。
- **不干扰手动电源键**：本功能只做“接入触发点亮”，不改变电源键、开关屏组合键的既有映射。

### 6.4 配置项

| 配置 | 默认值 | 说明 |
|---|---|---|
| 手柄接入点亮屏幕 | 开 | 总开关 |
| 点亮后自动解锁 | 关 | 需 root；默认只亮屏显示锁屏 |
| 防抖窗口 | 3s | 同手柄重复添加事件去重 |
| 点亮反馈 | Toast + 短震 | 可关闭 |

## 7. 非功能需求

- 端到端延迟目标：按键/摇杆到系统响应 < 50ms（root 内核级注入）。
- 连续操作 10 分钟无漂移、无卡顿、无事件堆积。
- 权限缺失时给出明确提示和回退动作，不静默失效。
- 日志可开关，记录原始事件、映射结果、注入结果，便于链路排查。
- 崩溃/重启后自动恢复配置和角色状态。
- 接入点亮失败不影响其他映射功能，不导致守护进程退出。
