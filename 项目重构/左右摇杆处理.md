# 滑动顺畅处理 · 总结

## 核心原则

顺畅 = **去噪 → 曲线 → 输出精度 → 收尾** 四层叠加，不是调一个灵敏度能解决的。光标和滑动共用“死区+滤波+曲线”，但输出方式和收尾逻辑不同。

---

## 一、左摇杆光标

**1. 死区分两层**
- 静止死区（径向）8%–10%，保证回中时光标绝对不动。
- 起步补偿：离开死区后输出不从 0 开始，直接跳到 0.03–0.05，消除“推了不动、再推就窜”的断层。

**2. 响应曲线**
- 用幂曲线（`输出 = 输入^1.5`）或分段曲线：低速平缓便于精点，高速变陡能跨屏。
- 用总灵敏度参数整体缩放，不要改曲线形状。

**3. 滤波**
- 优先 **One Euro Filter**：慢移强滤波压抖，快移弱滤波保跟手。
- 低成本替代：低速段强 EMA（`alpha=0.5–0.7`），高速段旁路或减弱。

**4. uinput 输出**
- 维护**浮点累加器**，不足 1 像素的余量保留到下一帧，亚像素精度输出。
- 不要每帧四舍五入到整数像素，否则轻推光标会“一跳一跳”。

**光标不需要惯性**，停在哪就是哪。

---

## 二、右摇杆滑动

**1. 滤波顺序**
先轻量滤波，再过死区。否则噪声会让滑动在死区边缘反复触发/取消，产生粘滞感。

**2. 用脉冲，不用持续速度**
- 推过死区触发一次明确距离的滑动脉冲（40–60% 屏高/宽），短暂间隔后若仍推着再触发下一次。
- 单次推杆 = 一次干脆翻页；长推 = 连续脉冲。不要直接映射“每秒滚多少像素”，否则停不准。

**3. 惯性只用于横向，且收尾要可控**
- 松手速度决定初始惯性，做上限截断防甩飞。
- 指数衰减（每帧 ×0.92–0.95）。
- 检测“摇杆快速回中”事件，额外加速衰减，模拟手指按住停下。

**4. 轴向锁定 + 互斥**
- 过死区后先判主方向，锁定 X 或 Y 轴，防斜推时上下+左右同时触发。
- 右摇杆离开死区 ↔ LB/RB 滑动互斥，最近输入抢占，避免速度叠加。

---

## 三、参数速查

| 环节 | 左摇杆光标 | 右摇杆滑动 |
|---|---|---|
| 死区 | 8%–10% + 起步补偿 0.03–0.05 | 7%–9%，过死区即触发脉冲 |
| 曲线 | 幂曲线 1.5 次，低速平高速陡 | 线性/轻指数，重点是脉冲阈值和步长 |
| 滤波 | One Euro 或低速强 EMA | 轻量 EMA，压推住时的速度抖动 |
| 输出 | 浮点累加，亚像素 | 脉冲式，避免微小滚动事件堆积 |
| 惯性 | 无 | 指数衰减，快速回中加速衰减 |
| 互斥 | — | 与 LB/RB 最近输入抢占，轴向锁定 |

---

## 四、验收标准

- 左摇杆轻推能稳定停在单个小图标上；快速甩动不拖沓；静止不漂移。
- 右摇杆单次推杆干脆翻一屏并停住；斜推不斜向乱滑；松手惯性自然收住。
- LB/RB 与右摇杆交替操作时，不出现速度叠加或“粘住”感。

**优先调这两项**：死区起步补偿、uinput 亚像素累加。对“不顺滑”的改善最直接。
