# Xbox Series X|S 手机全局映射 · 最终总结

## 一、技术前提 （参考）

https://github.com/yaragirodev/OneControllerX
- 刷 **OneControllerX**（Magisk），让 Share 键在 Android keylayout 中稳定暴露，避免只读到 `KEYCODE_MEDIA_RECORD`。
- 守护进程用 **evdev 直接读手柄 + uinput 内核注入**，不要每次按键 fork `su -c input`。
- 组合判定窗口 **30–60ms**；修饰键按下先 pending，组合优先并抑制单键动作；单击动作延迟到窗口结束，但按下瞬间短震。
- 守护进程只允许固定命令白名单：通知栏、媒体键、音量、缩放、锁屏/开关屏、`force-stop` 当前前台包名；不开放任意 shell。
- 模式切换、组合识别、滚动档位给不同震动反馈。

## 二、单击映射

| 按键 | 动作 | 说明 |
|---|---|---|
| **A** | 鼠标左键；最近输入是 D-pad 时 = 激活焦点 | 输入源自动切换 |
| **B** | 返回 | |
| **X** | 无单击动作；按下短震 | 按住 X = 媒体/横滑/慢速修饰；X 双击 = 多任务 |
| **Y** | Home（唯一 Home 入口） | |
| **LB** | 向上快速滑动，按住连续 | 步长 40–60% 屏高；长按 200ms 后加速 |
| **RB** | 向下快速滑动，按住连续 | 同上；X 按下后按 RB 转为右滑 |
| **LT** | 缩小，按住连续 | 依赖系统缩放权限；不可用时震动提示并回退 |
| **RT** | 放大，按住连续 | 同上 |
| **L3** | 单击 = 光标居中 | 居中后 200–300ms 或摇杆回死区前忽略左摇杆 |
| **R3** | 单击 = 静音；双击 = 播放/暂停 | 双击窗口内右摇杆移动则取消 |
| **START** | 切换上一个 App | 单击即时 |
| **SELECT** | 下拉通知栏/快捷设置 | root 下稳定 |
| **GUIDE** | 单击 = 无动作；**单独长按 >800ms = 映射帮助/悬浮菜单** | X 按住或 800ms 内 X 按下则取消帮助，转入强停计时 |
| **SHARE** | 单击 = 开/关强制鼠标映射模式，持久化；长按无动作 | 切换给 Toast + 长震 |
| **方向键** | 原生 D-pad | 不与 X 组合时正常移动焦点/选择 |
| **左摇杆** | 鼠标指针：加速度 + 刹车曲线 + 死区 + 边缘减速 | 核心调校 |
| **右摇杆 ↑↓** | 精细滚动，短推小步、长推加速 | 与 LB/RB 互斥 |
| **右摇杆 ←→** | 精细横向滑动：死区 + 加速 + 惯性 + 轴向锁定 | 与 X+LB/RB 大段横滑分工不同 |

## 三、组合键

| 组合 | 动作 | 左右手分工 | 说明 |
|---|---|---|---|
| **X + ↑** | 音量 +：单击一档，按住 300ms 后连续 | 右手拇指 X + 左手拇指 ↑ ✓ | 抑制 D-pad 移动 |
| **X + ↓** | 音量 −：单击一档，按住 300ms 后连续 | 右手拇指 X + 左手拇指 ↓ ✓ | 同上 |
| **X + ←** | 上一首 | 右手拇指 X + 左手拇指 ← ✓ | 单击一次，不连续切歌 |
| **X + →** | 下一首 | 右手拇指 X + 左手拇指 → ✓ | 同上 |
| **X + LB** | 向左大段滑动，短按约 50–70% 屏宽；按住 300ms 后连续 | 右手拇指 X + 左手食指 LB ✓ | 抑制 LB 上滑；跨手平衡 |
| **X + RB** | 向右大段滑动，短按约 50–70% 屏宽；按住 300ms 后连续 | 右手拇指 X + 右手食指 RB ⚠ 同侧 | 唯一同侧持续项；短按脉冲为主，长按 300ms 后才连续；期间抑制 RB 下滑 |
| **X 按住 + 左摇杆** | 慢速指针（0.35–0.5×） | 右手拇指 X + 左手拇指摇杆 ✓ | 无方向键、无 LB/RB、无 GUIDE 时生效 |
| **X 双击** | 最近任务/多任务 | 右手拇指瞬态 | 仅 X 单独快速双击；伴随方向/肩键/摇杆/GUIDE 时不触发 |
| **X + GUIDE 长按 1.5s** | **直接强制停止当前前台应用，无确认** | 右手拇指 X + 另一拇指伸到顶部 GUIDE | 优先级最高；抑制 GUIDE 帮助和系统行为、X 双击和其他 X 组合；中途释放取消；执行后长震 + Toast 显示包名 |
| **GUIDE 单独长按 >800ms** | **映射帮助/悬浮菜单** | 单手拇指伸到顶部 | X 按住或 800ms 内 X 按下则取消帮助，转入强停计时 |
| **SELECT + START 长按 1s** | 开/关屏幕切换 | 左手 View + 右手 Menu ✓ | 抑制 START 单键切 App |
| **L3 单击** | 光标居中 | 左手拇指瞬态 | 居中后忽略左摇杆 200–300ms 或回死区 |
| **R3 双击** | 播放/暂停 | 右手拇指瞬态 | 双击窗口内右摇杆移动则取消；R3 单击=静音 |

**明确不做**：截图、亮度调节、LT+方向、LT+左摇杆、L3/R3 组合前缀、LB+RB 强停、Share 长按帮助、Share 截图、窗口管理组合。

## 四、GUIDE 判定逻辑

1. **X 已按住时按 GUIDE** → 直接进入 `X+GUIDE` 强停计时，长按 1.5s 执行；不触发帮助。
2. **X 未按住时按 GUIDE** → 启动 GUIDE 单独长按 800ms 计时：
   - 800ms 内 X 按下 → 取消帮助，转入 `X+GUIDE` 强停计时（从 X 按下起算 1.5s）；
   - 800ms 内无 X 按下 → 触发帮助；此后 X 再按下不转强停，直到 GUIDE 释放。
3. 强停期间抑制 GUIDE 系统行为（助手/游戏栏）、X 双击和其他 X 组合；任一键释放取消。
4. 帮助显示期间，GUIDE 释放关闭帮助；X 按下不触发强停。

## 五、X 状态机优先级

X 按下 → pending 30–60ms，短震。按优先级：

1. **GUIDE 按下** → `X+GUIDE` 强停计时，最高优先级，抑制 X 其他语义和 GUIDE 系统行为。
2. **方向键 ↑/↓/←/→** → 音量/切歌，抑制 D-pad 移动。
3. **LB/RB** → 左滑/右滑，抑制 LB/RB 上下滑动；`X+RB` 连续调整延迟到 300ms 后启动。
4. **左摇杆离开死区且无方向/肩键/GUIDE** → 慢速指针。
5. **X 单独释放** → 250–300ms 双击候选窗口；再次按 X → 多任务，长震；无第二次 → 无动作。
6. X+方向/X+肩键/X+左摇杆/X+GUIDE 期间，不触发双击多任务。

## 六、调校参数

- 左摇杆：死区 6%–8%；非线性加速度；X/Y 独立灵敏度；边缘减速 30%–50%。
- 右摇杆：死区后轴向锁定；纵向重复 80–120ms，加速后 30–50ms；横向带惯性和轻微回弹。
- LB/RB 上下滑动：步长 40–60% 屏高；长按 200ms 后加速；松手即停。
- X+LB/RB 横滑：短按一次 50–70% 屏宽；按住 300ms 后连续，间隔 100–150ms；松手即停。
- 音量：X+↑/↓ 单击一档；按住 300ms 后连续，间隔 100ms；松手即停。
- 缩放：LT/RT 按住连续，速率可调；松手即停；不可用时震动提示并回退。
- 滚动/滑动互斥：右摇杆离开死区暂停 LB/RB；LB/RB 按下暂停右摇杆纵向；X+LB/RB 期间抑制单键上下滑动；最近输入抢占。
- L3 居中后 200–300ms 或摇杆回死区前忽略左摇杆。
- R3 双击播放/暂停：窗口内右摇杆移动则取消。
- A 键自动语义：最近 D-pad → 激活焦点；左摇杆离开死区 → 鼠标左键并显示光标；SHARE 做强制鼠标模式兜底。
- Profile 持久化：手机默认/精细点击/信息流三套；记录死区、加速度、滑动步长、缩放速率、组合窗口、SHARE 鼠标模式。

## 七、速览

| 类别 | 映射 |
|---|---|
| **强制项** | LB=上滑，RB=下滑；X+LB=左滑，X+RB=右滑 |
| **音量/切歌** | X+↑=音量+，X+↓=音量−；X+←=上一首，X+→=下一首 |
| **缩放** | LT=缩小（按住连续），RT=放大（按住连续） |
| **慢速指针** | X 按住 + 左摇杆 |
| **强停** | **X + GUIDE 长按 1.5s 直接强停前台应用，无确认** |
| **帮助** | **GUIDE 单独长按 >800ms = 映射帮助/悬浮菜单**；X 按住时 GUIDE 长按走强停 |
| **高频单击** | A=左键/焦点激活，B=返回，Y=Home，左摇杆=指针，右摇杆=精滚/精细横滑 |
| **低频单击** | L3=居中，R3=静音，R3 双击=播放/暂停，SELECT=通知栏，START=上一个 App，SHARE 单击=鼠标模式（长按无动作），GUIDE 单击无动作 |
| **其他双手组合** | SELECT+START 长按 1s=开关屏，X 双击=多任务 |
| **唯一同侧项** | X+RB 右滑：短按脉冲为主，长按 300ms 后才连续 |
| **不映射** | 截图、亮度、LT+方向、LT+左摇杆、L3/R3 组合前缀、LB+RB 强停、Share 长按帮助 |

**设计原则**：`X+↑=音量+` 等语义保留直觉；持续组合左右手分工，唯一同侧项 X+RB 用脉冲式滑动缓解；L3/R3 只做瞬态单击/双击，不做组合前缀；强停低频且不顺手，帮助回 GUIDE 单独长按。
