# 真机验证记录

设备：Samsung SM-F9360（Galaxy Z Fold4），Android 16（API 36，`BP2A.250605.031.A3.F9360ZSSAIZF1`），
KernelSU root，adb over TCP `192.168.10.36:6666`。
外接显示：HDMI 2560×1600（`displayId=8`，`FLAG_EXTERNAL_DEX_HOSTING`，DeX 桌面在跑 `com.honeyspace.dexservice.SecondaryLauncher`）。
手柄：`Xbox Wireless Controller`（`/dev/input/event19`，Classes `KEYBOARD|GAMEPAD|JOYSTICK|VIBRATOR|EXTERNAL`）。
注入用虚拟手柄：`work/scripts/vgpad.c`（uinput，045e:0b13，与真实 Xbox 同 descriptor 族）。

## 1. 反编译

| 步骤 | 命令 / 结果 |
|---|---|
| 拉取 | `adb pull /data/app/.../base.apk`（8.27 MB）+ `split_config.xxhdpi.apk` |
| 反编译 | jadx 1.5.0 ✓（另有子任务用 apktool 拆 smali 交叉校验 `onKeyEvent`/`m2127C`） |
| 规模 | App 自身只有 4 个类：`MainActivity`(4450 行)、`MouseAccessibilityService`(4963 行)、`R`、`VerticalFriendlySeekBar`；其余逻辑被 R8 内联进 `p000.*` |

## 2. DeX 侧行为实测

| 实验 | 结果 |
|---|---|
| `dumpsys accessibility` | Display[0]=`[KeyboardInterceptor, MotionEventInjector]`；**Display[8]=`[MotionEventInjector]`** → DeX 上无键盘拦截 |
| 注入虚拟手柄摇杆，观察 App 覆盖窗口 | 窗口是 DeX 焦点窗口，但 `onGenericMotionEvent` 从未被调用 |
| `dispatchGesture` 点击 DeX 任务栏 Play 商店 | 无反应；`mFocusedApp` 不变 |
| `/dev/uinput` 鼠标 + `REL_X/Y` + 右键 | DeX 桌面右下角弹出"壁纸/小部件/设置"右键菜单 ✓ |
| uinput 鼠标左键（`BTN_LEFT`） | 由同一注入通道，行为一致（右键菜单即证明） |

## 3. 复刻版功能实测

| 用例 | 期望 | 实测 |
|---|---|---|
| 鼠标模式开关（广播 `com.dennis.gamepadmouse.TOGGLE`） | 日志 `mouse mode ON/OFF`，光标窗口出现/消失 | ✓ |
| **手柄 L3 开关**（root 原始事件通道，Linux `BTN_THUMBL`=317） | 恰好在"检测到手柄 → 按下 L3"后 **一次** 切换，并随即 `grabbed: 0 <手柄名>` | ✓（修复了"无障碍事件与 root 事件双重处理导致连切两次"的 bug） |
| L3 再按一次（已独占状态） | 一次 `mouse mode OFF`，释放独占 | ✓ |
| 16 ms 帧循环移动 | 摇杆满偏 1.5 s，光标 x 1260 → 2540（触边钳制） | ✓ |
| 点击 | 日志 `primary down` → `tap at x,y disp=8`（gesture）/ `BTN_LEFT`（native） | ✓ |
| 双击/右键 | `double tap at ...` / native `BTN_RIGHT` → DeX 右键菜单 | ✓ |
| DeX 显示自动选择 | 服务启动时选中 `displayId=8`（2560×1600） | ✓ |
| root helper 直连（unix socket） | `connected to helper socket ...` → `helper ready` | ✓ |
| **helper 跨 App 重启存活** | 助手为常驻 daemon：一个客户端断开后回到 `accept()`，App 重装/服务重启后自动重连（实测重装 APK 后立即 `connected to helper socket` + `helper ready`） | ✓ |
| 手柄独占 | 见下方 A/B | ✓ |

### 3.1 屏蔽效果 A/B（核心验收）

DeX 显示上打开系统「设置」，注入 `KEY_BACK`（Linux 158）：

```
### A) 鼠标模式 OFF（未独占）
before: topResumedActivity=...com.android.settings/.Settings$ConnectionsSettingsActivity
after : topResumedActivity=...com.sec.android.app.launcher/...SecondaryLauncher   ← 系统收到了 BACK

### B) 鼠标模式 ON（EVIOCGRAB 独占）
before: topResumedActivity=...com.android.settings/.Settings$ConnectionsSettingsActivity
after : topResumedActivity=...com.android.settings/.Settings$ConnectionsSettingsActivity  ← 系统完全收不到
```
