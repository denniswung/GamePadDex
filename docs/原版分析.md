## 1. 整体架构

```
MainActivity（设置 UI，单 Activity + DrawerLayout + 6 个页面容器）
        │  ← 只通过 SharedPreferences("GamepadMousePrefs") 通信，没有广播/绑定
        ▼
MouseAccessibilityService（AccessibilityService）
  ├─ 光标：WindowManager 覆盖窗口（TYPE_ACCESSIBILITY_OVERLAY）里的 ImageView
  ├─ 移动：16 ms Runnable（s60 case 6）按摇杆单位速度积分
  ├─ 点击：dispatchGesture(Path, 50 ms)  ← 触摸注入
  ├─ 拖拽：StrokeDescription(willContinue) + continueStroke（40 ms 节流）
  ├─ 滚动：150 ms 滑动（起点 (cursorX, H/2)）
  ├─ 摇杆：p000/t60（View.onGenericMotionEvent，要求窗口获得焦点）
  ├─ 按键：AccessibilityService.onKeyEvent（FLAG_REQUEST_FILTER_KEY_EVENTS）
  └─ 屏幕键盘：DeX 用两벌式韩文/英文/西语键盘覆盖窗口（m213x 那一大段）
```

* APK 里有 AdMob + Firebase + Play Billing + `com.pairip`（LicenseActivity，反篡改/许可校验）。
  这些与功能无关，复刻版全部剔除。
* 原版 Pro 能力：自定义映射、震动强度、DeX 锁屏、DeX 指针速度、屏幕键盘、R3 切屏、去广告。
  复刻版全部免费开放。

## 2. 关键数值（与复刻版一致）

| 项 | 值 |
|---|---|
| 光标帧循环 | 16 ms；`cursor += 摇杆单位 * speed(px/帧)` |
| 指针速度 | 手机 `pref_mouse_speed`=50 px/帧；DeX `pref_dex_speed`=35 px/帧 |
| 死区 | `pref_deadzone`/100，默认 0.15 |
| 灵敏度曲线 | `a=(sens-1)/2`（sens=pref/10，默认 2.0）；`out = t^2.5·a·0.9 + (1-0.9a)·t`，`t=(|stick|-dz)/(1-dz)` |
| 单击 | 50 ms 单点 Stroke |
| 长按→拖拽 | 按住 >250 ms 且移动，或静止按住 >500 ms |
| 双击 | 两次 50 ms Stroke，间隔 150 ms |
| 滚动 | 150 ms 滑动；位移 `pref_scroll_speed/50 * 180 * (1 手机 / 0.5 DeX)` px |
| 光标窗口 | `(size, size, TYPE_ACCESSIBILITY_OVERLAY, 792, TRANSLUCENT)`，`gravity=START|TOP`；外接屏尺寸 ×0.4 |
| 焦点捕获窗口 | `(15,15, 2032, 262432, -3)`，每个 STATE_ON 的显示一个 |
| 自动隐藏 | `pref_mouse_timeout` 秒（0=不自动关） |

## 3. 键位语义（原版实测语义，复刻版已对齐）

鼠标模式下：

| 输入 | 行为 |
|---|---|
| A（`swap_ab` 时 B） | 单击 / 按住拖动 |
| B（`swap_ab` 时 A） | 返回（先给覆盖窗口加 `FLAG_NOT_FOCUSABLE`，50 ms 后 `performGlobalAction(BACK)`） |
| X | 组合键修饰符（按住 X 时 L1/L2/R1/R2/D-Pad 触发用户映射 slot） |
| Y | 播放/暂停 |
| L1 / R1 | 上一曲 / 下一曲 |
| D-Pad 左 / 右 | 快退 / 快进 |
| R3 | 切换活动显示（手机 ↔ DeX） |
| L3（`pref_toggle_keycode`=106） | 进入/退出鼠标模式（可配长按时长） |
| START / SELECT | Home / 最近任务 |
| 右摇杆 | 滚动（纯水平方向不滚动——原版怪癖，已保留） |

映射 slot 共 8 个：`lb, rb, lt, rt, up, down, left, right`，存储键
`pref_mapping_x_<slot>_{type,value,interval}`；动作 id 共 15 个：
`none, launch_app, home, recents, vol_up, vol_down, mute, bright_up, bright_down,
media_forward, media_rewind, screenshot, rotate, click_location, click_location_repeat`。
`click_location*` 的 value 是 `"x,y"` 字符串；重复点击默认 500 ms（100–3000）。

## 4. 原版在 DeX 下的真实缺陷（复刻版重点修复）

1. **DeX 显示上 `KeyboardInterceptor` 不启用** → `onKeyEvent` 收不到手柄按键 → D-Pad 落到桌面 Launcher，变成"方向键导航图标"。
2. **摇杆 MotionEvent 到不了无障碍覆盖窗口**（即使窗口是焦点窗口）→ DeX 下模拟摇杆移动不可靠。
3. **`dispatchGesture` 注入的是触摸**，DeX 桌面/任务栏只认鼠标事件 → 点不动。

复刻版的修复见 [`DEX-屏蔽方案.md`](DEX-屏蔽方案.md)。

## 5. 复刻版实现差异（有意为之）

| 项 | 原版 | 复刻版 |
|---|---|---|
| 手柄独占 | 无 | root `EVIOCGRAB`（核心需求） |
| DeX 指针 | 自绘光标 + 触摸 | 可选原生 uinput 鼠标（默认，DeX 必需） |
| 输入读取 | 覆盖窗口 MotionEvent + 无障碍按键 | 优先 root 原始事件；无 root 时退回原版方式 |
| 广告/内购/埋点/pairip | 有 | 全部移除 |
| 屏幕键盘覆盖层 | 有（韩/英/西，两벌式） | **未移植**（UI 上已注明） |
| 语言 | en/ko/es | 英文（沿用原版英文文案） |
