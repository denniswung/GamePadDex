> **主要依据**
> - `项目重构/手柄按键处理.md`：默认映射、X 状态机、GUIDE 判定、组合表、互斥、调校参数。

>
> **辅助依据**：`项目重构/通用控制器控制手机程序.md`（窗口/优先级/持久化/接入点亮）、`项目重构/经验交接报告.md`（已知坑）。

> 状态标记：**✅ 已实现**（v2.0 代码已具备）；**⚠️ 部分**（有近似实现但参数/行为不符）；**❌ 未实现**（按文档应做，当前没有）。本轮**只列用例，不执行**。

## 0. 通用约定

| 项 | 说明 |
|---|---|
| 设备 | SM-F9360，Android 16，KernelSU，Debug APK（`DebugReceiver` 可用） |
| 门禁 | 每个脚本先跑 `dexpad_precondition.sh`；未过即中止 |
| 稳定环境 | `am force-stop` 后重启服务；`screen_off_timeout=600000`；`svc power stayon false`；`wm dismiss-keyguard` |
| 注入器 | `vgpad key/hold/double/combo/stick/hat`，`pre=3000` 留设备发现时间 |
| 证据 | `logcat -s DexPadV2`、`/data/adb/gpm/helper.log`、`dumpsys input` hover、prefs XML、`dumpsys power/window` |
| 判定 | 日志计数为准；指针/屏幕状态为辅；同一用例失败重试 1 次再判 |
