## 光标空闲隐藏后的恢复：改成「隐形恢复」，不再有可见的修正移动

### 上一版做错了什么

v1.64 为了让光标回到上次位置，用的是"重建鼠标设备 + 有界到左上角 + 按增益一步到位"的
**绝对定位**。问题是这个修正过程是**看得见的**：光标的真实位置在重建后我们已经不管了，
助手会先把光标推到左上角再拉回来——用户看到的就是"光标先跳到角落、再飞回来"。

### 这版的结论（实测发现）

鼠标设备**销毁再重建后，系统会保留光标的坐标**（不是重置）。
也就是说：根本不需要任何修正移动。

实测（CursorTestActivity，隐藏前光标在 `1789,797`）：

```
空闲 10 秒 → 设备销毁，光标瞬间消失
推一下摇杆 → 设备重建，光标直接出现在 1789,797（0px 误差）
点击落点: MOUSE/click-down x=1789 y=797
```

### 现在的实现

- **隐藏**：销毁虚拟鼠标设备（`h`）——光标瞬间消失，最干净；
- **恢复**：只重建设备（`j`），**不做任何移动**——光标直接出现在上次位置；
- 不存在"从角落飞回来"的修正过程，也就不会再有"修正时很奇怪"的观感；
- 只在 L3（主动居中）时才会移动光标，那是用户明确要求的动作。

实测日志：

```
engine: pointer shown at last position (no correction move)
helper: MOUSE_REOPEN (auto) | POINTER on
```
