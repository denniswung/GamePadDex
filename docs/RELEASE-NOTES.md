# v1.53 发布说明（2026-11-14）

包名：`com.dennis.dexpad`　versionCode **54** / versionName **1.53**
配套：KernelSU 模块 `gpm_dex` v1.53 · 助手 `gpminput` v1.53

## 本版修好三件事

### 1. 杀应用没有真的杀死

**原因有两个**：
- 默认配置里**根本没有"杀应用"的绑定**：GUIDE 单键被 `handleSpecial()` 拦去做"长按显示帮助"，短按什么都不做；X+GUIDE 的强杀需要持续按住 800 ms 才触发，实际很难命中。
- 助手的 `f` 只从一条 `dumpsys activity | grep | sed` 管道取包名，取不到就直接放弃，且没有兜底。

**改法**：
- **GUIDE 短按 = 强杀前台应用**（长按仍是帮助；X+GUIDE 保留）；
- 助手 `f` 依次尝试 `dumpsys activity` / `dumpsys window` / 缓存的前台包名，然后
  `am force-stop <pkg>` **并且** 直接 `SIGKILL` 该包所有进程（保证进程真的没了）。
- `cmd_close_app()`（原 ALT+F4 路径）同样补了 SIGKILL 兜底。

### 2. 无法模拟电源键

**原因**：助手用 `system("input keyevent 26")`，但在这个 SELinux 域里 `input` 时好时坏
（同样的调用在别处返回过 `rc=512`），有时命令执行了却没有任何效果。

**改法**：优先用**我们自己虚拟键盘的 `KEY_POWER`**（`EV_KEY 116`，内核级，不经过 binder），
失败才退回 `input keyevent 26`。日志会写 `POWER uinput=1`。

### 3. 光标居中（第三次修，这次是"有界步进"）

**原因**：之前用一次 `-30000` 的巨量位移把指针"顶"到左上角，指针加速会把光标直接甩出屏幕，
之后连 hover 都没有——表现就是"居中了但光标不见了/没居中"。

**改法**：
1. 把"回左上角"拆成 **40 个有界小步**（每步约 1.2 屏 / 40 / 增益），指针稳定停在 (0,0)；
2. 再按增益**一步**走到屏幕中心 `(w/2, h/2)`；
3. 增益从设置页「居中增益」（100–400%，默认 216%）读取，落点偏差可直接微调。

## 使用说明（重要）

- 手柄按钮只在**鼠标模式开**时生效（通知栏显示"鼠标模式：开"）。鼠标模式关时手柄已交还系统，
  所有映射按键都不动作——这是设计，不是故障。用 **SHARE** 切换。
- 杀应用：**短按 Xbox 键（GUIDE）**；想连按两次确认也可以（X+GUIDE 仍然保留）。
- 电源键：**Y + L3**。
- 居中：**L3**；偏了就在设置里调「居中增益」。
