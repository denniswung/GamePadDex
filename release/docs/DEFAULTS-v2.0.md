# GamePadDex v2 默认配置

| 项 | 默认 |
|---|---|
| 左右摇杆角色 | 左=光标，右=滑动/滚动（可互换） |
| 光标速度 | 1.0×（0.2–3.0） |
| 滑动速度 | 1.0×（0.2–3.0） |
| 死区 | 8%（3–20%） |
| 响应曲线 | 1.5 次幂 |
| 起步补偿 | 0.04 |
| 滤波 EMA α | 0.6 |
| 边缘减速 | 40% |
| 输出后端 | 手势滑动（可切滚轮） |
| 单次步长 | 50% 屏高/宽 |
| 持续启动延迟 | 150 ms |
| 持续重复间隔 | 100 ms |
| 加速后间隔 | 40 ms |
| 横向惯性 | 0.93/帧 |
| 组合窗口 | 50 ms |
| 长按阈值 | 500 ms |
| 双击窗口 | 280 ms |
| 接入点亮 | 开（不解锁） |
| 点亮防抖 | 3 s |

## 默认按键

| 键 | 动作 |
|---|---|
| A | 左键 |
| B | 返回 |
| X | 多任务 |
| Y | 主屏幕 |
| LB / RB | 上滑+持续 / 下滑+持续 |
| LT / RT | 缩小 / 放大（按住） |
| L3 | 光标居中 |
| R3 | 静音 |
| START | 切换软件 |
| SELECT | 通知栏 |
| GUIDE | 无 |
| SHARE | 开/关映射 |
| 方向键 | 系统方向键 |

## 默认组合（发起键命名空间）

| 组合 | 动作 |
|---|---|
| X + ↑ / ↓ | 音量 + / − |
| X + ← / → | 上一首 / 下一首 |
| X + LB / RB | 向左滚动 / 向右滚动 |
| Y + L3 | 开/关屏幕 |
