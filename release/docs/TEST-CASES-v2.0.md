# GamePadDex v2.0 详细测试用例（未执行）

> 目标：覆盖《通用控制器控制手机程序》需求文档 4.1–4.4、5.1–5.4、6.1–6.4、7、8 的验收条款。
> 约定：**A**=自动可脚本化；**M**=需要人工/物理操作（插拔、蓝牙配对）；**P0**=验收必过，**P1**=重要，**P2**=边界。
> 环境：SM-F9360（Android 16，KernelSU），Debug APK（`DebugReceiver` 可用），`vgpad`、`PointerProbeActivity`、`/data/adb/gpm/helper.log`、`logcat -s DexPadV2`。
> 测试前统一：`am force-stop com.dennis.dexpad` → 起服务 → `dexpad_precondition.sh` 门禁；`screen_off_timeout=600000`、`svc power stayon false`。

## 0. 判定依据（所有用例通用）

| 依据 | 来源 | 用途 |
|---|---|---|

| `helper.log` | `/data/adb/gpm/helper.log` | `SWIPE/WHEEL/POWER/WAKE_CONNECT/ANCHOR/KEY/DEV` 判定 |
| 指针坐标 | `PointerProbeActivity` + `dumpsys input` hover（全屏时等价全局） | 位移/速度/居中 |

| 窗口 | `dumpsys window` 的 `NotificationShade` 计数 | 通知栏 |
| 配置注入 | `am broadcast -a com.dennis.dexpad.V2 -n com.dennis.dexpad/.DebugReceiver …` | 仅 Debug 构建 |

## A. 链路与自检（前置，P0，A）

| ID | 用例 | 步骤 | 预期 | 优先级 |
|---|---|---|---|---|
| A-01 | 助手进程存在 | `pidof gpminput` | 返回 pid | P0 |
| A-02 | socket 建立 | `ls -l …/files/gpm.sock` | 存在且可读写 | P0 |
| A-03 | READY 握手 | `grep '^READY' helper.log` | 有 | P0 |
| A-04 | 设备枚举 | `grep '^DEV ' helper.log` | ≥1 条（
`Virtual Test Gamepad` 或实体手柄） | P0 |
| A-05 | 抓取成功 | `grep '^GRABBED' helper.log` | 对应设备 | P0 |
| A-06 | 真实按键往返 | `vgpad key 304 120` + 日志 | `single a -> left_click` | P0 |
| A-07 | 自检命令 | `echo '?' \| nc -U …/gpm.sock` 或 UI「Root 助手自检」 | `SELFTEST ndev=… grab=1 wake_on=1 wake=1` | P1 |
| A-08 | 链路中断即中止 | 杀助手后跑门禁 | 门禁 `exit 2`，不进入功能用例 | P0 |

## 10. 判定阈值汇总

| 指标 | 阈值 |
|---|---|
| 单击次数 | 恰好 1 次（日志计数） |
| 长按触发 | 阈值 ±80ms |
| 双击窗口 | 配置 ±60ms |
| 组合命中 | 0 条单键动作 |
| 轴锁 | 单次输出仅 1 轴 |
| 持续输出间隔 | 配置 ±40ms |
| 脉冲距离 | 50%±5% 屏高 |
| 指针速度比 | 3.0×/0.2× ≈ 15±3 倍位移 |
| 居中 | 屏幕中心 ±10px |
| 点亮 | Dozing→Awake，≤3s |
| 防抖 | 3s 内 ≤1 次点亮 |
| 延迟 | <50ms（logcat 时间戳） |
