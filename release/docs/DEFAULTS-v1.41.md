# GamePadDex 默认配置快照（v1.41，2026-11-12 冻结）

> 本文件记录移除 DeX 支持前的最终默认配置。后续版本（v1.42 起）只支持手机自带屏幕，
> 按键默认值与此表保持一致（DeX 专属动作已移除）。

## 1. 单击映射

| 按键 | 默认动作 |
|---|---|
| A | 鼠标左键 `left_click`（方向键导航时 = 激活焦点） |
| B | 返回 `back` |
| X | 多任务 `recents` |
| Y | 主屏幕 `home` |
| LB | 向上滑动+持续滚动 `scroll_swipe_up` |
| RB | 向下滑动+持续滚动 `scroll_swipe_down` |
| LT | 缩小 `zoom_out` |
| RT | 放大 `zoom_in` |
| L3 | 光标居中 `center_cursor` |
| START | 切换软件 `switch_app` |
| SELECT | 最大化窗口 `maximize_window`（DeX 专用，v1.42 移除） |
| GUIDE | 键盘快捷键 `key_combo` = `alt+f4` |
| SHARE | 开/关鼠标模式 `toggle_mouse` |
| ↑ / ↓ / ← / → | 系统方向键 `arrow_*` |
| 左摇杆 | 鼠标指针 |
| 右摇杆 ↑↓←→ | 连续翻页/滑动 |

## 2. 双击

| 按键 | 动作 |
|---|---|
| X | 切换软件 `switch_app` |

## 3. 组合键

| 槽位 | 组合 | 动作 |
|---|---|---|
| 0 | X + ↑ | 音量增加 `volume_up` |
| 1 | X + ↓ | 音量减小 `volume_down` |
| 2 | X + ← | 上一首 `prev_track` |
| 3 | X + → | 下一首 `next_track` |
| 4 | X + LB | 向左滚动 `wheel_left` |
| 5 | X + RB | 向右滚动 `wheel_right` |
| 9 | Y + L3 | 开/关屏幕（电源键）`power` |

## 4. 数值默认

| 设置 | 默认 |
|---|---|
| 指针速度（DeX/手机） | 30 / 30 px/帧 |
| 摇杆死区 | 16%（160/1000） |
| 滚动速度 | 4 |
| 滚动死区 | 35%（350/1000） |
| 水平滑动速度 | 7 |
| 方向键步长 | 36 px |
| 滚轮速度（按住持续） | 3（≈186 ms/格，1 格） |
| 上下滑动用触摸拖动 | 开 |
| 反向滚动 | 关 |
| 强制横屏 | 开 |
| 鼠标模式 | 开（持久化） |

## 5. 手势几何（v1.41）

- 竖向普通滑动：50% 屏高 / 200 ms；信息流 30% / 150 ms；桌面底部起手 45% / 200 ms；下拉通知栏顶边 3%。
- 缓慢滑动：25% 屏高（320–900 px）/ 120 ms。
- 滑动+滚动：先 25% 快滑，再持续滚动（上下 80 ms、左右 140 ms）。
- 光标居中：夹角落 + 线性增益（本机实测 3.25），一次到屏幕中心。

## 6. v1.43 手势统一（取代按 App 适配）

- 上推：65% 起手 / 35% 屏高 / 450 ms，连续排程（间隔 40 ms）。
- 下拉：顶边 3% 起手 / 45% 屏高 / 200 ms，一次一放。
- 缓慢滑动：25% 屏高 / 120 ms。
- 不再有信息流「一条一次」、桌面「一次一格」的自动区分。
