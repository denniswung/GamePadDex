## 按键默认值（依据《手柄按键处理》）

| 按键 | 动作 |
|---|---|
| A | 鼠标左键（方向键后 = 激活焦点，v1.43 原生导航逻辑） |
| B | 返回 |
| X | **单击无动作**；**双击 = 多任务** |
| Y | 主屏幕 |
| LB / RB | 向上 / 向下快速滑动（按住连续） |
| LT / RT | 缩小 / 放大（按住连续） |
| L3 | 光标居中 |
| R3 | 单击静音；**双击 = 播放/暂停** |
| START | 切换上一个应用 |
| SELECT | **下拉通知栏** |
| GUIDE | 无单击动作 |
| SHARE | 开/关映射 |
| 方向键 | 系统方向键 |
| 组合 X+↑/↓ | 音量 + / − |
| 组合 X+←/→ | 上一首 / 下一首 |
| 组合 X+LB/RB | 向左 / 向右滚动 |
| 组合 Y+L3 | 开/关屏幕（保留 v1.43 既有习惯） |

## 未包含（相对《手柄按键处理》文档的差距）

- GUIDE 长按 800ms 帮助、X+GUIDE 长按 1.5s 强停、SELECT+START 长按 1s 开关屏、X+左摇杆慢速指针、X+LB/RB 50–70% 屏宽连续滑动：这些在 v2 里实现过但引入了稳定性问题，本版未移植；待旧骨架稳定后再单独评估。
- 摇杆按《左右摇杆处理》仅作参考，不改动 v1.43 参数。
