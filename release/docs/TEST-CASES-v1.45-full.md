## 0. 约定

- 设备：SM-F9360（Android 16，KernelSU），Debug APK（`DebugReceiver` 可用）。
- 测试前统一：`am force-stop com.dennis.dexpad` → 起服务 → `dexpad_precondition.sh` 门禁；`screen_off_timeout=600000`；`svc power stayon false`；`wm dismiss-keyguard`。
- 注入：`vgpad key/hold/double/combo/holdstick/hatkey`；周期性动作使用单进程 `combo`/`holdstick` 避免虚拟设备竞态。
- 证据：`logcat -s DexPadV2`、`/data/adb/gpm/helper.log`、`dumpsys input` hover、`dumpsys power/window`、prefs XML。
- 优先级：P0=验收必过；P1=重要；P2=边界。类型：A=自动；M=人工/物理。
