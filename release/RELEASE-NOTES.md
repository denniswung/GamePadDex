# v1.55 发布说明（2026-11-14）

包名：`com.dennis.dexpad`　versionCode **56** / versionName **1.55**
配套：KernelSU 模块 `gpm_dex` v1.55 · 助手 `gpminput` v1.55

## 修的问题：光标点击没反应

**原因**：v1.54 把 A 键改成了"在光标位置注入真实触摸"。但触摸事件**必须带精确坐标**，
而我们拿不到系统指针的真实位置（这台机 `dumpsys` 的指针读数不可靠），只能用引擎自己估算的
`ptrX/ptrY`。一旦估算和真实光标有偏差，点击就落在别的地方——表现就是"点了没用/点错位置"。

对比一下：**鼠标左键事件本身不带坐标**，系统按真实光标位置处理，所以永远不会点错。

## 改法

左键注入方式改成**可选项**，默认回到鼠标事件：

| 设置项 | 默认 | 行为 |
|---|---|---|
| 「左键注入方式：触摸点击」 | **关** | A = 鼠标左键事件（系统按真实光标位置点击，最可靠；按住即长按） |
| 同上，打开 | — | A = 在光标位置注入真实触摸（只给"只认触摸事件"的 App 用；坐标来自估算，可能偏） |

- d-pad 模式下 A 仍然是「确认焦点」（`DPAD_CENTER`），不受影响。
- 设置页位置：「设置 → 手柄鼠标 → 左键注入方式：触摸点击」。

## 其它（v1.54 保留）

- **LT / RT = 以光标为基准的双指缩放**（按住连续；d-pad 模式走 `Ctrl±`）。
- 新增动作 **「打开目标应用」**（默认不绑键，设置页选目标 App 后自行绑键）。

## 已知限制

- 触摸点击模式（需手动开启）依赖光标位置估算，长距离移动后可能偏，**建议只在鼠标点击无效的 App 里临时打开**。
- 触摸点击/双指缩放走默认显示的虚拟触摸屏，DeX 外接屏暂未验证。
- 带双击动作的按键（如 R3）单击会延迟一个双击窗口（320 ms）才触发。
