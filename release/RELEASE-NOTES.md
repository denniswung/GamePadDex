# v1.58 发布说明（2026-11-14）

包名：`com.dennis.dexpad`　versionCode **60** / versionName **1.58**
配套：KernelSU 模块 `gpm_dex` v1.58 · 助手 `gpminput` v1.58

## 1. 映射列表精简（46 → 38 项）

去掉了重复或几乎没人用的动作，选动作时更好找：

| 移除 | 原因 |
|---|---|
| `SLOW_SWIPE_*`（4 个） | 和 `SWIPE_*` 重复，只是慢一点 |
| `SCROLL_SWIPE_LEFT/RIGHT` | 左右方向很少用；竖向的 LB/RB 默认还在 |
| `MINIMIZE` | 等同于 `HOME` |
| `CLOSE_WINDOW` | 等同于 `FORCE_STOP`（都是杀前台应用） |

> 被移除的动作**常量仍然保留**：老配置里已有的映射照样能执行，只是不再出现在选择列表里。

## 2. 「打开目标应用」选不了应用 —— 已修

**根因**：Android 11+ 的**包可见性限制**。应用清单里没有 `<queries>` 声明时，
`PackageManager.queryIntentActivities(...)` 只会返回极少数应用（甚至 0 个），
于是弹出来的列表是空的、看着就是"选不了应用"。

**改法**：
- `AndroidManifest.xml` 增加 `<queries>`（MAIN/LAUNCHER），实测现在**能看到 47 个可启动应用**；
- 三处入口都能选目标应用：**按键详情页**（单击/双击/长按）、**组合键槽位**、**映射列表长按**；
- 列表为空时自动降级为**手动输入包名**，并提供「手动输入包名」按钮兜底；
- 摘要里会显示已选的应用包名；启动前校验包名（不含 `.` 的非法值不再盲目 `am start`）。

## 3. 代码审计修复（本轮改动）

按"会失效/会卡"的顺序：

1. **扳机要踩到 75% 才触发** → 有右摇杆的手柄，Z/RZ 按单极 0..1 归一，半程即触发（默认 LT/RT=缩放，现在好用）。
2. **「居中增益」滑杆无效** → 助手之前只解析 `O` 命令的前 4 个参数，第 5 个（增益）被丢弃；现已生效。
3. **自定义快捷键大多无效** → 组合键映射表只支持 A–E/F4/CTRL/ALT 等少数键，`ctrl+alt+f`、`win+d`、`f5`
   全被静默丢弃；已补全字母、数字、F1–F12、空格/回车/ESC/方向键/PageUp-Down/Win 等。
4. **连接重启线程竞态** → `RootInput.restart()` 期间旧连接线程可能和新线程同时存在、互相覆盖 socket，
   重连后命令写进无人接收的 socket（点击/移动静默丢失）；已加"代次"守卫，旧线程必退。
5. **手柄掉线后按住状态不清** → 滚动/按住动作会一直持续到切模式；掉线现在会一起释放（鼠标、触摸、滚轮、缩放）。
6. **组合键"打开目标应用"无法配 App** → 组合槽现在也会弹应用选择器，存进 `mix_value`。
7. **导出配置自我嵌套** → 导出时排除 `profiles` / `profile_*`，避免保存/加载配置互相覆盖。
8. **「水平滑动速度」滑杆无效** → 已接入横向翻页节奏。
9. **GUIDE 映射成"打开应用"时参数错** → 短按 GUIDE 现在走和其它按键一致的参数解析。
10. **日志刷屏** → 关闭每轴事件的 `AXMAP` 调试日志（长期运行会写满 `/data` 并拖慢输入）。
11. **GONE 事件缺设备名** → 助手释放设备时补上名字，设置页的设备列表不会残留旧手柄。
12. **映射列表长按** → 现在长按某个键可直接换动作（之前 `chooseAction` 根本没被调用）。

## 已知限制

- 应用列表只显示"有启动入口（LAUNCHER）"的应用；系统内部页面请用「手动输入包名」。
- 触摸点击模式（需手动开）仍依赖光标位置估算，可能点偏。
- 已审计但本轮未改（风险/收益比低，留待后续）：`cmd_swipe` 里的 `dumpsys` 仍是同步调用（滑动瞬间有百毫秒级延迟）、
  `send()` 无写超时、`isPhone()` 恒真导致 DeX 分支是死代码。
