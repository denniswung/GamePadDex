# v1.56 发布说明（2026-11-14）

包名：`com.dennis.dexpad`　versionCode **58** / versionName **1.56**
配套：KernelSU 模块 `gpm_dex` v1.56 · 助手 `gpminput` v1.56

## 本版修的三件事

### 1. 右摇杆向上拨动不滚动

**原因**：右摇杆的竖向滚动走"真实触摸拖动"，向下拨用的是**从屏幕顶部 3% 起手**的拖动手势——
那是为了"拉通知栏"设计的，从顶部起手会被系统当成下拉状态栏，页面根本不滚。

**改法**：两个方向都改成**中屏拖动**：

| 摇杆 | 手指示意 | 起点 | 终点 | 效果 |
|---|---|---|---|---|
| 向上拨 | 手指向下拖 | 30% 高 | +35% 高 | 内容回到上方（往上滚） |
| 向下拨 | 手指向上拖 | 65% 高 | −30% 高 | 内容继续往下（往下滚） |

实测手势：上滚 `776,480 -> 776,1040`、下滚 `776,1040 -> 776,560`（屏幕 2560×1600）。

### 2. 每个按键各自配置「打开目标应用」

去掉原来那个**全局**「目标应用」设置。现在目标应用是**每个映射槽自己的参数**：

- 进入某个按键的详情页（「设置 → 手柄鼠标 → 按键映射 → 某个键」）；
- 把**单击 / 双击 / 长按 / 组合**任意一槽的动作选成「打开目标应用」；
- 选完动作会**弹出应用列表**，给**这一槽**挑一个 App（列表里会标 ✓ 显示当前已选）。

也就是说同一个「打开应用」动作，可以给不同按键配不同的 App，互不影响。

### 3. D-pad 无法连发

**原因**：方向键只处理"按下"那一次，没有键盘式的自动重复。

**改法**：按住方向键 **400 ms** 后开始连发，之后每 **110 ms** 一次，松开立即停止。
实测按住 1.5 秒发出 **11 次**（未改之前只有 1 次）。

## 顺带修正

- v1.55 打出来的包内部版本号误标成了 1.54 / versionCode 55（版本号替换没生效）。
  v1.56 已改为 **1.56 / versionCode 58**，并重新出包；v1.55 的 Release 已撤下，避免下到标错版本的包。

## 已知限制

- 触摸点击模式依赖光标位置估算，可能点偏（默认不用它）。
- DeX 外接屏上的触摸/缩放/滚动路径尚未完整回归。
- 带双击动作的按键（如 R3）单击会延迟一个双击窗口（320 ms）。
