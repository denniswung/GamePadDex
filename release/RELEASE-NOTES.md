# v1.54 发布说明（2026-11-14）

包名：`com.dennis.dexpad`　versionCode **55** / versionName **1.54**
配套：KernelSU 模块 `gpm_dex` v1.54 · 助手 `gpminput` v1.54

## 本版三个改动

### 1. 放大 / 缩小 = 以光标为基准的双指手势

- 新增**虚拟触摸屏**（`Gamepad Touch Panel`，多点协议 B：`ABS_MT_SLOT` / `TRACKING_ID` / `POSITION`，`INPUT_PROP_DIRECT`）。
- **LT / RT**：在**光标所在位置**做双指缩放，按住期间**连续**推帧（约 70 fps，两指间距每帧 ±9，
  范围 24 px ~ 屏高/3）。松手立即结束，不会留下残留触点。
- **d-pad 模式**（原生方向键导航状态）下自动退回 **Ctrl + - / Ctrl + +**：日志会写
  `zoom out -> [113, 69]` 与助手 `KCOMBO`，不再发触摸手势。

### 2. 鼠标左键 = 模拟屏幕点击（支持长按）

- A 键不再注入鼠标左键事件，而是在**光标位置注入一次真实触摸**（`EV_KEY BTN_TOUCH` + 单指
  `ABS_MT_*`）：
  - 按下 → 触点按下；松开 → 触点抬起，中间**不移动**，所以就是一次点击；
  - **按住不放 = 长按**（信息流/短剧/长按菜单都能用）。
- d-pad 模式保持原样：A = **DPAD_CENTER（确认焦点）**。
- 指针被「空闲隐藏」时按 A 会先恢复指针再点击。

### 3. 新增动作「打开目标应用」

- 动作表新增 `open_app`（显示为 **打开目标应用**），**默认不绑定任何按键**，需要自己挑一个键。
- 目标应用在设置页「打开目标应用」里选（列出所有可启动应用，显示名称 + 包名）。
- 真正启动走 **root 助手的 `am start`**：后台服务自己 `startActivity` 会被系统拦截，
  实测走助手后前台能正确切过去。

```

PASS  鼠标模式开                   PASS  A = 屏幕点击（touch down/up）
PASS  A 长按（按住 900ms 后抬起）

PASS  d-pad 模式 LT = Ctrl + -
```

补充证据：

- 双指帧在内核侧确认有两个触点：`ABS_MT_TRACKING_ID 0x0b / 0x0c`、`ABS_MT_SLOT 0/1`，
  两指位置分别落在光标左右（`0x3bff` / `0x43ff`，即 1280,800 ± 80）。
- 「打开目标应用」在 Release 版实测：`open app com.android.settings` →
  `OPEN_APP rc=0` → 前台切到 `com.android.settings/.Settings`。

## 使用提示

- 缩放若在某些 App 里没反应，多半是该 App 本来就不支持缩放（不是手势没发出去）。
- 双指缩放期间摇杆仍然可以移动光标（缩放基准点在按下那一刻固定）。
- 动作映射可在「设置 → 手柄鼠标 → 按键映射」里给任意按键绑定 `打开目标应用`。

## 已知限制

- 触摸设备坐标按当前窗口尺寸（含横竖屏）换算，切换分辨率/旋转后会重新同步（最多 2 秒）。
- 虚拟触摸屏走的是"默认显示"，DeX 外接屏（display 9）上的触摸点击/缩放暂未验证。
- 快速点按带"双击动作"的按键（如 R3）时，单击动作会延迟一个双击窗口（320 ms）才触发。
